# Catch the Eggs 🥚

A browser arcade game: chickens drop eggs, and you move the basket with your mouse to catch them.

## Features
- Start screen and loading page
- Basket that follows the mouse
- Lives and records shown in the navbar
- Game over and restart

## Built With
JavaScript, jQuery, SCSS, Bootstrap
